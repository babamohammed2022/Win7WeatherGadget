# Windows 7 Weather Gadget

This repository contains a restoration of the **Windows 7 Weather Gadget**, adapted to work on modern Windows systems.

## Features

* Windows 7-style weather gadget
* Support for multiple languages
* Weather information and forecasts
* Configurable location and units
* Windows 7-inspired interface

## Installation

Download the latest release and run the installer:

**`Win7WeatherGadget-Setup.exe`**

Follow the installation wizard to install the gadget and its required components.

## Compatibility

Designed for modern Windows versions with support for Windows Sidebar/Gadgets.

## Building from Source

Clone the repository and follow the build instructions provided in the project documentation.

The installer can be built using **Inno Setup**.
